# BoardShelf

Android-приложение для каталогизации настольных игр в стиле деревянного стеллажа из референса.

## APK

После push GitHub Actions автоматически собирает debug APK. Открой **Actions → Build BoardShelf APK → последний запуск → Artifacts → BoardShelf-debug**.

## Запуск

Откройте репозиторий в Android Studio и запустите модуль `app`.
